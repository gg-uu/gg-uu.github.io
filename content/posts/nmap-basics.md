Nmap（Network Mapper）是安全从业者使用频率最高的信息收集工具之一。它的核心能力包括主机发现、端口扫描、服务/版本识别和操作系统指纹探测。这篇文章从原理讲起，逐步覆盖实战中最常用的参数组合。

## 扫描原理

Nmap 通过发送不同类型的探测报文，并分析目标返回的数据包来推断端口状态。三种最常见的扫描方式：

| 扫描方式 | 报文类型 | 优点 | 缺点 |
| --- | --- | --- | --- |
| TCP Connect | 完整 TCP 三次握手 | 准确、无需特权 | 速度慢、日志明显 |
| SYN 半开扫描 | 只发送 SYN | 速度快、隐蔽性好 | 需要 root 权限 |
| UDP 扫描 | UDP 报文 | 发现 UDP 服务 | 慢、易误报 |

## 常用参数

### 主机发现与存活探测

```bash
# Ping 扫描，探测哪些主机在线
nmap -sn 192.168.1.0/24

# 不做 ICMP，直接端口扫描
nmap -Pn 192.168.1.10
```

### 端口扫描

```bash
# 常见 1000 端口
nmap 192.168.1.10

# 全端口（1-65535）
nmap -p- 192.168.1.10

# 指定端口范围
nmap -p 80,443,8080-8090 192.168.1.10
```

### 服务与版本识别

```bash
# 服务版本探测（推荐，信息更全）
nmap -sV 192.168.1.10

# 操作系统指纹识别
nmap -O 192.168.1.10

# 综合探测：服务版本 + 系统指纹 + 默认脚本
nmap -sC -sV -O 192.168.1.10
```

> 提示：`-sC` 会执行默认脚本，`-sV` 做版本探测，两者结合能拿到非常完整的服务信息，是实战中最常用的组合。

### 脚本引擎（NSE）

Nmap 自带的脚本引擎可以完成漏洞检测、暴力破解等扩展任务：

```bash
# 列出所有脚本
ls /usr/share/nmap/scripts/

# 使用特定脚本检测
nmap --script=http-headers 192.168.1.10

# 使用漏洞类脚本
nmap --script=vuln 192.168.1.10
```

## 输出格式

```bash
# 保存为 XML（便于后续解析）
nmap -oX result.xml 192.168.1.10

# 保存为 grepable 格式（脚本处理友好）
nmap -oG result.txt 192.168.1.10

# 三种格式同时输出
nmap -oA scan_result 192.168.1.10
```

## 实战建议

1. **先做全端口快速扫描**，再用 `-sV` 精确识别，避免在慢速 UDP 上浪费过多时间。
2. **结果一定要导出**，后续漏洞验证和报告撰写都依赖完整的扫描记录。
3. 扫描前确认授权范围，Nmap 的主动探测会产生明显网络流量与日志，务必在合法授权下使用。
